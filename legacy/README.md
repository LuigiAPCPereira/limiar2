## limiar2

[limiar2/](limiar2/) contém a implementação sobrevivente anterior à reconstrução L3, incluindo módulo Go, código, testes, workflows, experimentos e documentação histórica/rebaseline.

Ela deve permanecer consultável e, quando proporcional, reproduzível. Não é autoridade arquitetural do Limiar 3 e não pode ser importada pelo código do root.

O repositório não contém uma implementação independente completa identificável do Limiar 1; apenas documentação histórica relata essa geração. Nenhum código L1 foi inventado nesta migração.
